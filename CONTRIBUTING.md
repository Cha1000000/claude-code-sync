# Contributing

Short version: **pull requests are not accepted, issues are welcome.**

This repository is a template, not a shared project. Everyone who uses it makes a
private copy of their own — press **Use this template**, set the new repository
to **Private**, and change anything you like there. Your copy is yours; nothing
needs to come back here.

Incoming pull requests are closed automatically, so please do not spend time on
one. (Forks cannot be disabled on a public personal repository, which is why this
is a policy and a bot rather than a setting.)

**Issues are a different matter.** Bug reports, questions and ideas are genuinely
useful — especially about operating systems this has seen less of. When reporting
a bug, the helpful details are:

- your OS and how Claude Code is installed;
- what you ran and what it printed (the engine's output is in Russian — paste it
  as is);
- whether `tools/tests/run-all.sh` passes on your machine.

Do not paste session transcripts, memory files or anything from your
`ccsync-secrets.env` into an issue.
