# Блок для вашего CLAUDE.md

Вставьте это в свой `~/.claude/CLAUDE.md`. Блок объясняет Клоду, что память
теперь общая на несколько машин, и как её такой сохранить.

Собственного `CLAUDE.md` хранилище намеренно **не** содержит: `pull`
перезаписывает этот файл всякий раз, когда он есть в хранилище, а ваши правила
шаблоном затираться не должны. Первый `push` заберёт получившийся файл и
развезёт его по остальным машинам.

Замените `~/claude-code-sync`, если склонировали хранилище в другое место.

---

```markdown
# Общее состояние на всех моих машинах (ccsync)

Этот файл, мои скиллы, команды, память и транскрипты сессий синхронизируются
между всеми моими машинами через приватный git-репозиторий
`~/claude-code-sync`. Машин несколько, ОС разные, список открытый.

## Где ты сейчас

В начале каждой сессии хук печатает блок `[ccsync] Машина: …`. **Это и есть
ответ на вопрос «где я».** Не определяй машину заново через `uname`, `hostname`
или содержимое каталогов — бери из этого блока. Паспорт машины лежит в
`~/.claude/ccsync-machine.json` (в git не попадает).

Память общая, поэтому в ней есть факты про **все** машины сразу. Локальный
`MEMORY.md` уже отфильтрован под текущую машину: разделы «Общее» и «Про эту
машину» применимы здесь, а раздел «Другие машины» — **нет**. Не переноси оттуда
решения, не проверив, что они годятся для текущей ОС.

## Как записывать новые факты

Файлы фактов живут в `~/.claude/projects/<слаг>/memory/facts/` (симлинк в
хранилище). `MEMORY.md` **собирается автоматически** — править его руками
бесполезно, изменения затрёт следующий `pull`.

Во frontmatter нового факта обязательны поля:

    metadata:
      type: user | feedback | project | reference
      scope: global                  # верно на всех машинах
      index_title: "Короткий заголовок для индекса"
      index_hook: "Сжатая суть в одну строку — то, что раньше писалось в MEMORY.md"

Значения `scope`:

- `global` — про меня, мою работу, проекты, домашнюю инфраструктуру, правила
  работы, поведение инструментов;
- `<machine-id>` (например `linux-desktop`) — установленный софт, драйверы,
  настройки рабочего стола, локальные окружения и пути **конкретной** машины;
- `os:linux` / `os:darwin` / `os:win32` — верно для любой машины с этой ОС;
- список: `[linux-desktop, work-laptop]`.

**Если сомневаешься — ставь машинный scope, а не global.** Ошибочный `global`
разносит локальное знание на все машины; ошибочный машинный лишь заставит
переспросить.

## MCP-серверы тоже со скоупами

По умолчанию сервер общий: поставил здесь — появился везде. Но если он завязан
на локальную БД, на собранный из исходников бинарь или на конкретную ОС, пометь
его сразу, не откладывая: `/sync-mcp <имя> --not-here` (везде, кроме этой
машины) или `--here` (только здесь). Иначе он поедет на остальные машины и
будет там молча падать при каждом старте сессии.

## Команды

- `/sync-push [all|session|tools|memory]` — отдать состояние в хранилище
- `/sync-pull [all|session|tools|memory]` — принять и разложить под эту машину
- `/sync-status` — что расходится
- `/sync-bind <ключ> [путь]` — привязать проект к пути на этой машине
- `/sync-mcp [имя] [--here|--not-here|--global]` — MCP-серверы и их scope
- `/sync-ignore [причина]` — не отправлять эту сессию в хранилище
- `/sync-forget [id]` — забыть сессию везде: и здесь, и на других машинах

Обычно звать их не нужно: `SessionStart` тянет, `Stop` и `SessionEnd` отдают.

## Приватная сессия

Если я говорю, что разговор не должен уехать на другие машины, — это
`/sync-ignore`, и ставить пометку надо **сразу**, не откладывая до конца
сессии: фоновый `Stop`-хук отправляет транскрипт каждые несколько минут, и всё
сказанное до пометки уже окажется в хранилище. Если это случилось, убрать
уехавшее умеет только `/sync-forget` — он же удаляет копию на остальных машинах.

`/sync-forget` необратим и удаляет локальный транскрипт (у живой сессии — при
её закрытии). Не запускай его вместо `/sync-ignore`, если я просил лишь
перестать синхронизировать.

## Чего не делать

- Не писать секреты в файлы хранилища. Токены — только в
  `~/.claude/ccsync-secrets.env` (локальный, в `.gitignore`).
- Не редактировать `MEMORY.md` и `memory/index.md` — они генерируются.
- Не подставлять абсолютные пути машины в файлы хранилища руками: пути
  токенизируются автоматически (`{{HOME}}`, `{{P:ключ}}`).
- Не править реестры `machines/` и `project-map/` за другие машины: каждая
  пишет только свой файл, на этом и держится отсутствие конфликтов слияния.
```
